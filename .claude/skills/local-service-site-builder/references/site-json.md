# File formats

```
sites/<slug>/
  site.json          business facts, services, areas, pricing, reviews
  design.json        generated by design_seed.py (editable)
  content/
    home.json  about.json  contact.json  [areas.json]
    services/<service-slug>.json      one per service (required)
    areas/<area-slug>.json            optional, one per community that gets its own page
  assets/            optional: img/, logo, og.png (1200x630)
  dist/              build output
```

## site.json

```jsonc
{
  "domain": "https://www.example-roofing.ca",      // final origin, no trailing slash
  "industry": "roofing",                            // see INDUSTRY_HUES in design_seed.py; also picks schema type
  "language": "en-CA",
  "min_words": { "service": 300, "area": 250 },     // optional: raise the floors for this site
  "business": {
    "name": "…", "legal_name": "…",
    "schema_type": "RoofingContractor",             // optional override (must be a schema.org LocalBusiness subtype)
    "phone": "+1-902-…", "phone_display": "(902) …", "email": "…",
    "address": { "street": "…", "city": "…", "region": "NS", "postal": "…", "country": "CA" },
                                                     // omit "street" for service-area businesses
    "geo": { "lat": 0, "lng": 0 },                  // optional
    "hours": [ { "days": ["Monday","Tuesday"], "opens": "08:00", "closes": "17:00" } ],
    "hours_text": "Mon–Fri 8–5",                    // short line for header/contact
    "hours_display": [ { "label": "Mon–Fri", "text": "8:00 AM – 5:00 PM" } ],
    "tagline_area": "Serving … and …",
    "founded": 2011, "license": "…", "price_range": "$$",
    "logo": "assets/img/logo.svg", "logo_width": 180, "logo_height": 48,   // optional; else a text logo
    "footer_blurb": "…", "social": ["https://…"]
  },
  "form": { "endpoint": "https://formspree.io/f/xxxx", "thank_you": "/thank-you/" },
  "og_image": "assets/og.png",
  "services_hub_h1": "…", "services_hub_description": "…",   // 110–160 chars
  "areas_hub_description": "…",                              // or content/areas.json
  "services": [ { "slug": "roof-replacement", "name": "Roof Replacement", "short": "One-sentence summary", "image": {…} } ],
  "areas":    [ { "slug": "gannet-point", "name": "Gannet Point" } ],
  "reviews":  [ { "author": "Dana R.", "area": "…", "source": "Google", "rating": 5, "text": "…" } ],
  "pricing": {                                     // omit the whole block for no calculator
    "currency": "CAD", "tax_rate": 0.15, "tax_label": "HST", "round_to": 5,
    "disclaimer": "…",
    "jobs": { "repair": "Repair", "maintenance": "Maintenance", "installation": "Installation" },
    "services": { "roof-replacement": { "installation": [9000, 18000] } },   // [low, high] before tax; omit job types a service doesn't offer
    "timing": { "standard": { "name": "Scheduled", "factor": 1.0, "note": "…" }, "emergency": { "name": "Emergency", "factor": 1.3 } },
    "regions": [ { "name": "Kestrel Bay", "factor": 1.0, "areas": ["kestrel-bay"] } ]   // every area slug must be in one region
  }
}
```

`"example": true` marks a fictional test site (allows 555 numbers and `.test` domains). Never set it on a real site.

## Page content (services/*.json, areas/*.json, about.json, contact.json, areas.json)

```jsonc
{
  "title": "30–60 chars, primary keyword + place + brand",
  "description": "110–160 chars, specific benefit, no keyword lists",
  "h1": "One clear H1",
  "lead": "1–2 sentence intro under the H1",
  "image": { "src": "assets/img/…", "alt": "…", "width": 1200, "height": 800 },   // optional
  "local_facts": ["…", "…", "…"],                 // areas/*.json only: at least 3, required
  "facts_heading": "What's different about … in …", // areas/*.json only, optional
  "sections": [
    { "type": "text",  "heading": "…", "html": "<p>…</p>" },
    { "type": "list",  "heading": "…", "items": ["…"], "intro_html": "<p>…</p>" },
    { "type": "steps", "heading": "…", "items": [ { "title": "…", "text": "…" } ] },
    { "type": "table", "heading": "…", "columns": ["…"], "rows": [["…"]], "note_html": "<p>…</p>" },
    { "type": "faq",   "heading": "…", "items": [ { "q": "…", "a": "…" } ] }
  ]
}
```

FAQ items on a page are also emitted as `FAQPage` structured data.

## home.json

```jsonc
{
  "title": "…", "description": "…",
  "hero":    { "eyebrow": "…", "h1": "…", "lead": "…", "points": ["…"], "cta": "Button text", "image": {…} },
  "trust":   [ { "icon": "shield|clock|tool|star|check|pin", "title": "…", "text": "…" } ],
  "services":{ "heading": "…", "lead": "…" },
  "pricing": { "heading": "…", "lead": "…" },
  "why":     { "heading": "…", "html": "<p>…</p>", "points": [ { "title": "…", "text": "…" } ], "image": {…} },
  "process": { "heading": "…", "steps": [ { "title": "…", "text": "…" } ] },
  "reviews": { "heading": "…" },
  "faq":     { "heading": "…", "items": [ { "q": "…", "a": "…" } ] },
  "areas":   { "heading": "…", "lead": "…" },
  "cta":     { "heading": "…", "lead": "…" },
  "contact": { "heading": "…", "lead": "…" }
}
```

The order of these sections on the page comes from `design.json → home_order`, and their layout from
`design.json → variants`.

## design.json (generated)

`colors`, `fonts`, `shape`, `layout`, `variants` (header, hero, services, why, process, reviews, faq, areas, cta,
footer), `home_order`, `class_prefix`. Safe to edit by hand: for example, set `colors.primary` to the brand
colour (keep white text readable on it) or swap `variants.hero` between `split`, `fullbleed` and `form`.
